# Privacy Policy

**Last updated: September 7, 2026**

Thread It is a Discord bot that moves replies into organized threads. This
policy explains what information Thread It handles when it is installed in a
server.

## Messages are not stored

Thread It does **not** store messages or attachments in a database. The bot
temporarily processes message data through Discord's API so it can create a
thread and repost the reply. Once that operation is complete, Thread It does
not retain the message content or attachment files.

Messages and attachments may continue to exist in Discord according to
Discord's own policies and the settings of the server where they were posted.

## Information the bot processes

To provide its features, Thread It may receive:

- Message content, replies, embeds, and attachments from Discord
- Discord IDs for messages, channels, users, and servers
- Server and channel permissions needed to create and manage threads

Thread It does not sell this information or use it for advertising. Operational
logs may contain limited metadata, such as IDs, counts, error details, and
timing information, for reliability and debugging. Message content is not
intentionally written to logs.

## Third-party services

Thread It uses Discord's API to receive events and perform actions. Discord's
handling of information is governed by [Discord's Privacy Policy](https://discord.com/privacy).

## Self-hosting

If you run your own instance of Thread It, you are responsible for the
deployment environment, logs, and any data retained by that environment.

## Changes and contact

This policy may be updated as Thread It changes. Questions or concerns can be
raised through the [Thread It issue tracker](https://github.com/wei/thread-it/issues).
